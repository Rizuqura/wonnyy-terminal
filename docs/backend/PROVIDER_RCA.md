## Baseline and chronology

The reported history is: Agent Chat previously generated text; later large requests (approximately 120K input/26K output) sometimes produced no visible answer; the modular backend and an application reset did not restore reliable output. That history is user-reported, not a reproduced last-good/first-bad bisect. A reset does not revert code, account access, encrypted profiles or external services.

Before production edits, [PROVIDER_BASELINE.md](PROVIDER_BASELINE.md) recorded versions/configuration and the supplied dirty tree. The original checkout remains on `main` at `9d524d6`. A separate worktree at `tmp/qt-rca-001`, branch `audit/qt-rca-001`, snapshots the supplied source at **829d704**. Compare audit repairs against that commit, not against the older main commit containing many unrelated differences. All 342 original source hashes still matched the baseline after audit execution. No personal profile/key/model selection was changed.

Observed diagnostic sequence:

1. Raw OpenRouter returned HTTP 200 and exact `QTERMINAL_OK` (16 input/6 output tokens, 1,328 ms), bypassing LiteLLM, routing, context, normal adapter completion and the agent runtime.
2. Raw saved NVIDIA model stalled before an HTTP response. This initially overlapped possible startup checks, so it was repeated after checks were explicitly stopped. It still timed out at 60,021 ms. A listed Mistral alternate returned HTTP 404 in 638 ms.
3. The actual experiment UI initially could not create a conversation: shared admission returned MODEL_BUSY; Send stayed disabled. Coordinating with normal model-check cancellation restored creation.
4. The next actual UI request reached routing but made zero provider calls. The exact manual model was rejected because the live catalog advertised `max_completion_tokens`, while the router required `max_tokens`.
5. Recognizing the output-cap alias and sending the advertised keyword restored actual OpenRouter streaming: deltas, usage, finish and exact final assistant bubble. The same path passed ORBITAL two-turn history and non-streaming JSON completion/rendering.
6. Deterministic failure UI checks exposed a separate code-visibility problem: the rejected IPC Error could overwrite the safe event error code. Retaining the structured event failure restored all six expected visible error cases. Controlled fallback and the existing normal agent/context Electron regression passed separately with synthetic responses.

# PDF token recovery and image text sources

PDF extraction errors no longer stay cached indefinitely for unchanged files. Context estimates, Active Context and source packages now request current indexed PDF text rather than substituting an empty string when the in-memory text is unavailable. The Context Box manager recomputes estimates when vault state reloads, offers **Refresh token estimates**, and displays per-file failure reasons. Counting text does not guarantee it fits the selected model's context window; existing budgets remain enforced without truncation.

PNG, JPG and JPEG files are visible/readable in Explorer and Planet View. Workspace shows the original image and a disclosure of locally extracted text. The formats participate in explicit source review, Context Boxes, agent single-file construction references, source identity validation and chat provenance. Providers receive OCR text, never image/base64 bodies. Photos/plots/charts are not visually interpreted; OCR can miss or misrecognize text, and the model request identifies it as OCR evidence.

Windows OCR runs in a hidden local PowerShell process using the installed Windows recognition language, with no cloud OCR dependency. Images are bounded to 25 MB and 100 megapixels, scaled before recognition and cached against a byte hash. Scanned/empty PDF pages render locally through the existing PDF.js canvas dependency, then use the same OCR engine. PDFs retain page markers, text-bearing pages remain usable if OCR is unavailable for empty pages, and all-empty sources remain empty. Scanned OCR is limited to 60 pages per document; over-limit and unavailable-language conditions explain how to recover. Original text PDF support remains available across platforms, while image/scanned OCR requires Windows.

Source path checks reject files whose resolved paths escape the vault. Temporary raster pages use isolated bounded temp directories and are removed after reading. The shipped OCR PowerShell script is unpacked from ASAR for installed builds. Existing provider settings, credentials, chat storage keys and immutable records are unchanged. The pre-existing user modifications in `electron/main.cjs` were preserved.

Verification: 272 tests pass, including real Windows OCR for all three image extensions and an image-only PDF, token estimates, source reads, changed images, page boundaries, blank pages and transient PDF recovery without editing the file. TypeScript/production build and `scripts/electron-pdf-image-smoke.cjs` pass. Electron verifies native OCR in the actual runtime, nonzero PDF/image Context Box estimates, failed-source repair/refresh, Workspace image preview, OCR text in actual provider requests, provenance and no hidden chats. Model responses are synthetic; OCR itself is real. Screenshots/logs are under ignored `test-results/`.

After updating, restart QTerminal, rescan the vault and use **Refresh token estimates**. Existing failed boxes do not need to be recreated. Any unreadable file reports its own reason; corrupt/password-protected documents remain unavailable rather than producing invented text. No installer or live-model visual-analysis validation was performed.

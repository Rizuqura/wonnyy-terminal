# Planet View sidebar

Latest density adjustment: all panel content (header, scroll body and footer) renders at 65% scale (30% larger than the previous 50%) within the same resizable panel geometry. The resize handle stays full size. This scales text, controls, icons and spacing together; the underlying base typography remains 12 pixels before scaling.

The Details + Context sidebar follows the supplied dark blue-black, cyan and amber reference. It keeps existing Station matching, source review, named Context Box creation, library management and provenance behavior. Brain Scope segments display the actual resolved mode; they do not imply a new scope-switching action.

Styling lives in `app/planet-sidebar.css`, scoped to the Planet sidebar. This intentionally restores the reference's subtle dividers/control edges in this area after the shared soft-surface rules. Source rows have file icons, full-path tooltips and truncation; missing/changed source states remain distinct. Saved box filters retain pressed state and a separate management action. The indexed footer uses the vault's real scan time.

Desktop width defaults to 360 pixels and can be dragged between 260 and 640 pixels, bounded to leave canvas space. Below 761 pixels the panel sits below the canvas and its top edge resizes its height. Pointer capture keeps dragging reliable outside the handle. Arrow keys resize, Shift increases the step, Home or double-click resets, and Escape cancels a drag. Width and height preferences survive reloads; shrinking the viewport clamps the displayed size without discarding the preferred size. The sidebar uses a 12-pixel body font matching Knowledge Vault file rows, with smaller secondary text. The header and footer stay outside the independent content scroller; long paths and names cannot widen it.

Verification: production build and TypeScript pass. `node scripts/electron-planet-sidebar-smoke.cjs` passes at 1920×1800, 1440×900, 1024×768, 800×650, 680×700 and 480×640.
